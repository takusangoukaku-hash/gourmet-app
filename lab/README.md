# ラボ片付け（`lab/`）

研究室の後片付け・依頼事項がすべて済んだかを一目で確かめる PWA。iPhone の時計アプリ（アラーム）風の一覧で、右のトグルをオンにすると完了。

- **後片付け**: 曜日で繰り返す（未選択は毎日）。完了はその日だけ有効で、翌日は自動でオフに戻る。今日が対象外の曜日のものは「ほかの曜日」に畳む。
- **依頼事項**: 一度きり。依頼者・期限・メモ。期限切れ／今日まで は赤、明日まで は橙。完了したら一覧の下に灰色で沈む。編集モードの「完了した依頼を消去」で片付ける。
- 上の大きな数字＝今日まだ済んでいない件数。0 になると「完了」。
- 行をタップで編集、「編集」で削除（元に戻す可）。
- データは端末の localStorage（`lab.tasks.v1`）だけ。端末間の同期はしない。

本番: https://takusangoukaku-hash.github.io/gourmet-app/lab/

バージョンは BITEMAP 本体と別: `js/app.js` の `APP_VERSION`、`sw.js` の `VERSION` と `SHELL` の `?v=`、`index.html` の `?v=`（2箇所）を揃える。
