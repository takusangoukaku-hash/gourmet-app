# 百名店チェック（`meimon/`）

百名店の一覧を自分で取り込み、行った店をチェックするだけの PWA。

- **店のデータはリポジトリに入れない**（公開リポジトリのため）。一覧は利用者がアプリの「データ」から貼り付けるか、テキストファイルを選んで取り込み、端末の localStorage にだけ保存する。外部への通信は地図を開いたときだけ（下記）。食べログなどから自動で集める処理は作らない。
- 取り込む形式: `# 一覧のタイトル`（例 `# 焼き鳥 EAST 2026`）の行で一覧を始め、続く行は `店名<TAB>都道府県 駅`、または位置つきの `店名<TAB>都道府県 駅<TAB>緯度,経度[,x|,c]<TAB>店のページのURL`（市の中心のおおよその位置は末尾に `,c`。例 `35.6,139.7,c`）。位置は数が2つで日本の範囲（緯度 20〜50・経度 120〜155）のときだけ受け、そうでなければ無視する。同じタイトルを取り込み直すとその一覧だけ置き換える。
- **「行った」は 店名＋都道府県 で覚える**（`meimon.visited.v1`。一覧とは別）。年が替わって一覧を貼り替えても、同じ店が別の一覧にあっても残る。一覧を削除しても消えない。
- ホーム: 全体の数、ジャンルごとの一覧（タイトル末尾の年と TOKYO／EAST／WEST などを除いたものがジャンル）、全リストからの検索（ひらがな・カタカナ・全角半角をそろえて探す）。
- 一覧: すべて／まだ／行った、都道府県、店名・エリアの絞り込み。行をタップで切り替え。
- 地図（v2〜。v3 で店の位置・色つきの地図・現在地）: 位置のある店が1つでもあるとホームに「地図」ボタン。同じ位置の店を1つの丸にまとめ（2店以上は数字。まとまりはズームで開く）、丸をタップすると店の一覧（行った／まだ・「地図アプリ」）。位置は3種類: `,x`＝店の位置（濃い小さな丸）／何も無し＝駅の位置／`,c`＝市の中心のおおよそ（薄い丸）。現在地は青い点（地図を開いている間だけ位置を見る。最初に開いたときだけ現在地へ寄せる）。地図は OpenFreeMap の bright（明）／fiord（暗）。外部への通信は、地図を開いたときの地図の部品（MapLibre、unpkg）とタイル（OpenFreeMap）だけで、店のデータは送らない。
- データ: 取り込む・バックアップの書き出し／読み込み（JSON。形と型を確かめる）・リストの削除・すべて消す。
- 店のページへのリンク（v5〜）: 行の4つ目の欄に店のページの URL（`https://tabelog.com/…/<id>/` の形だけ受ける）があると、一覧の行と地図のシートに「食べログ」のリンクが出る。
- v27: 「区・市ごと」は「20店以上」も選べる。店の数の絞り込みは「駅ごと」と「区・市ごと」で別々に覚える。
- v26: 店の数の絞り込みを「すべて／3店以上／5店以上／10店以上」から選べる（右端のボタン → 選択肢）。
- v25: 並びは1つのボタン（今の並びの名前 ⌄）にまとめ、押すと「店の多い順／割合の高い順／残りの少ない順」の選択肢が開く。
- v24: 並びのボタンの文字を「店数順／割合順／残り順」に短くし、「3店以上」まで1行に収めた。
- v23: 「区・市ごと」「駅ごと」の並びに「残り少ない順」（まだ行っていない店が少ない順。全部行った所は後ろ。行に「あと N」）。
- v22: 「区・市ごと」「駅ごと」に「3店以上」の絞り込み（店が 3 店に満たない駅・区を隠す。選んだ状態を覚える）。
- v21: 「区・市ごと」「駅ごと」の並びを「店の多い順／割合の高い順」で切り替えられる（選んだ並びを覚える）。
- v20: 行の 12 個目の欄に駅のまとまり（例 `新宿駅周辺`）があると、「駅ごと」でその名前にまとめる。ホームの題の横と一覧の下にアプリの版と一覧を取り込んだ日時。版が上がったときは「v20 に更新しました」、開いている間に新しい版が入ったら「新しい版があります ・ 更新」の帯。
- v19: エリア別で都道府県を開くと「店／区・市ごと／駅ごと」で切り替えられる。区・市ごとは、行の 11 個目の欄に市区町村（例 `渋谷区`）がある一覧のときに出る。
- v18: ホームを「ジャンル別／エリア別」で切り替えられる。エリア別は都道府県ごとの行った数と割合（同じ店は1店と数える）。行を押すとその都道府県の店の一覧。数の横に割合（「3 / 100 ・ 3%」）。
- v17: 題の末尾が「3.7以上」の一覧（例 `ラーメン TOKYO 3.7以上`）も、百名店と同じジャンルにまとめる。百名店でない店を別の一覧として足せる。
- v16: 行の 10 個目の欄に待ち時間のページ（gyouretsu-yosoku.com の店ごとの記事）の URL があると、店の行に「待ち時間」のリンクを出す。数字そのものは持たない。
- v15: 行の9つ目の欄に店の公式サイトの URL があると、店の行に「公式サイト」のリンクを出す。
- v12: 祝日（暦を計算）と第N曜日の定休日を見る。店の行は「営業中 ・ 22:30 まで／営業時間外 ・ 17:00 から」。一覧にも「営業中」の絞り込み。店の行の「地図」でその店へ地図を寄せる。地図の左下の「近い順の一覧」（v13 で文字つきのボタンに）で、見えている範囲の店を近い順に並べる。不定休・臨時休業は分からない。
- 営業時間（v11〜）: 行の8つ目の欄に営業時間（例 `月・火 11:30 - 14:00、17:00 - 22:00 / 土 11:30 - 15:00`）があると、店の行に「営業中／営業時間外」と今日の営業時間を出し、地図では営業時間外の店を白抜きの丸にする。地図の上の「営業中」で、いま開いている店だけに絞れる。臨時休業は分からない。
- 電話番号と予約サイト（v10〜）: 行の6つ目の欄に電話番号、7つ目の欄に予約サイトの URL（https）があると、店の行と地図のシートに「電話」「予約」のリンクを出す。
- 料理の系統の色（v9〜）: 地図の「まだ」の丸は料理の系統の色（肉／和食／麺／洋食／中華・アジア／酒／甘味・喫茶。ジャンルは一覧の題から）。行った店は灰。違う系統が混ざるまとまり・同じ位置は濃い灰。寄ると（z14〜）丸の下に店名とジャンル。左下の色の説明はタップで畳める。
- 下のタブ（v8〜）: リスト／地図 をタブで行き来する。地図の見た目は BITEMAP 本体と同じ（`js/mapstyle.js`＝本体の `baseMapStyle` の写し）。地図を開いたときの通信は unpkg（MapLibre）・tiles.openfreemap.org（タイル）・maps.gsi.go.jp（地図の文字）。
- 定休日（v7〜）: 行の5つ目の欄に定休日の文（例 `月曜日、日曜日`）があると、行に「定休 …」を出し、今日が毎週の定休日なら「今日は定休日」。地図ではその店を白抜きの丸にする。営業時間が無い店は定休日だけで判定する。
- 位置を自分で直す（v4〜）: 地図の丸をタップ → 店の行の「位置を直す」→ 地図を動かして中央の印を店の場所に合わせ「この位置にする」。直した位置は `meimon.pos.v1` に持ち、一覧の位置より優先。一覧を貼り替えても残り、バックアップにも入る。「元に戻す」で一覧の位置に戻る。
- 記録するのは 行った／まだ だけ（日付・メモ・評価・写真・ログイン・同期は無い）。
- localStorage: `meimon.lists.v1`（一覧）・`meimon.visited.v1`（行った店）・`meimon.pos.v1`（自分で直した位置）。キャッシュ名は `meimon-*`。
