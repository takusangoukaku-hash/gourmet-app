# 百名店チェック（`meimon/`）

百名店の一覧を自分で取り込み、行った店をチェックするだけの PWA。

- **店のデータはリポジトリに入れない**（公開リポジトリのため）。一覧は利用者がアプリの「データ」から貼り付けるか、テキストファイルを選んで取り込み、端末の localStorage にだけ保存する。外部への通信は地図を開いたときだけ（下記）。食べログなどから自動で集める処理は作らない。
- 取り込む形式: `# 一覧のタイトル`（例 `# 焼き鳥 EAST 2026`）の行で一覧を始め、続く行は `店名<TAB>都道府県 駅`、または位置つきの `店名<TAB>都道府県 駅<TAB>緯度,経度[,x|,c]<TAB>店のページのURL`（市の中心のおおよその位置は末尾に `,c`。例 `35.6,139.7,c`）。位置は数が2つで日本の範囲（緯度 20〜50・経度 120〜155）のときだけ受け、そうでなければ無視する。同じタイトルを取り込み直すとその一覧だけ置き換える。
- **「行った」は 店名＋都道府県 で覚える**（`meimon.visited.v1`。一覧とは別）。年が替わって一覧を貼り替えても、同じ店が別の一覧にあっても残る。一覧を削除しても消えない。
- ホーム: 全体の数、ジャンルごとの一覧（タイトル末尾の年と TOKYO／EAST／WEST などを除いたものがジャンル）、全リストからの検索（ひらがな・カタカナ・全角半角をそろえて探す）。
- 一覧: すべて／まだ／行った、都道府県、店名・エリアの絞り込み。行をタップで切り替え。
- 地図（v2〜。v3 で店の位置・色つきの地図・現在地）: 位置のある店が1つでもあるとホームに「地図」ボタン。同じ位置の店を1つの丸にまとめ（2店以上は数字。まとまりはズームで開く）、丸をタップすると店の一覧（行った／まだ・「地図アプリ」）。位置は3種類: `,x`＝店の位置（濃い小さな丸）／何も無し＝駅の位置／`,c`＝市の中心のおおよそ（薄い丸）。現在地は青い点（地図を開いている間だけ位置を見る。最初に開いたときだけ現在地へ寄せる）。地図は OpenFreeMap の bright（明）／fiord（暗）。外部への通信は、地図を開いたときの地図の部品（MapLibre、unpkg）とタイル（OpenFreeMap）だけで、店のデータは送らない。
- データ: 取り込む・バックアップの書き出し／読み込み（JSON。形と型を確かめる）・リストの削除・すべて消す。
- 店のページへのリンク（v5〜）: 行の4つ目の欄に店のページの URL（`https://tabelog.com/…/<id>/` の形だけ受ける）があると、一覧の行と地図のシートに「食べログ」のリンクが出る。
- 位置を自分で直す（v4〜）: 地図の丸をタップ → 店の行の「位置を直す」→ 地図を動かして中央の印を店の場所に合わせ「この位置にする」。直した位置は `meimon.pos.v1` に持ち、一覧の位置より優先。一覧を貼り替えても残り、バックアップにも入る。「元に戻す」で一覧の位置に戻る。
- 記録するのは 行った／まだ だけ（日付・メモ・評価・写真・ログイン・同期は無い）。
- localStorage: `meimon.lists.v1`（一覧）・`meimon.visited.v1`（行った店）・`meimon.pos.v1`（自分で直した位置）。キャッシュ名は `meimon-*`。

本番: https://takusangoukaku-hash.github.io/gourmet-app/meimon/

バージョンは BITEMAP 本体と別: `js/app.js` の `APP_VERSION`、`sw.js` の `VERSION` と `SHELL` の `?v=`、`index.html` の `?v=`（2箇所）を揃える。
