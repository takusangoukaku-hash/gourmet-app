# 百名店チェック（`meimon/`）

百名店の一覧を自分で取り込み、行った店をチェックするだけの PWA。

- **店のデータはリポジトリに入れない**（公開リポジトリのため）。一覧は利用者がアプリの「データ」から貼り付けるか、テキストファイルを選んで取り込み、端末の localStorage にだけ保存する。外部への通信はしない（食べログなどから自動で集める処理は作らない）。
- 取り込む形式: `# 一覧のタイトル`（例 `# 焼き鳥 EAST 2026`）の行で一覧を始め、続く行は `店名<TAB>都道府県 駅`。同じタイトルを取り込み直すとその一覧だけ置き換える。
- **「行った」は 店名＋都道府県 で覚える**（`meimon.visited.v1`。一覧とは別）。年が替わって一覧を貼り替えても、同じ店が別の一覧にあっても残る。一覧を削除しても消えない。
- ホーム: 全体の数、ジャンルごとの一覧（タイトル末尾の年と TOKYO／EAST／WEST などを除いたものがジャンル）、全リストからの検索（ひらがな・カタカナ・全角半角をそろえて探す）。
- 一覧: すべて／まだ／行った、都道府県、店名・エリアの絞り込み。行をタップで切り替え。
- データ: 取り込む・バックアップの書き出し／読み込み（JSON。形と型を確かめる）・リストの削除・すべて消す。
- 記録するのは 行った／まだ だけ（日付・メモ・評価・写真・ログイン・同期は無い）。
- localStorage: `meimon.lists.v1`（一覧）・`meimon.visited.v1`（行った店）。キャッシュ名は `meimon-*`。

本番: https://takusangoukaku-hash.github.io/gourmet-app/meimon/

バージョンは BITEMAP 本体と別: `js/app.js` の `APP_VERSION`、`sw.js` の `VERSION` と `SHELL` の `?v=`、`index.html` の `?v=`（2箇所）を揃える。
